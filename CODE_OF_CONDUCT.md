# Code of Conduct

This project adopts the Contributor Covenant, version 2.1, as its code of conduct. The full text is at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>. It applies to every space of the project: issues,
pull requests, discussions and reviews.

## Reporting

To report unacceptable behavior, open a confidential security advisory on this repository on GitHub, or contact the
repository owner through GitHub. Reports are handled privately.
